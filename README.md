## Open Source

### 🔴 [Paranoid](https://github.com/theAstiv/paranoid)
> Self-hosted, iterative threat modeling with LLMs

STRIDE · MAESTRO · DREAD scoring · Deterministic fallback · npm dependency capability engine · Anthropic / OpenAI / Ollama · Async Python

Threat modeling is critical and consistently under-resourced. Paranoid makes it fast enough to actually happen, and keeps working without an LLM when you need it to.
`Presented at Black Hat India Arsenal 2026 · VulnCon Arsenal 2026`

---

### 🔵 [context-link](https://github.com/theAstiv/context-link)
> MCP server for token-efficient AI coding agent context

Go · SQLite FTS5 · Tree-sitter · 11 languages · `v1.0.0`

Gives AI coding agents structured, token-efficient codebase context, with blast radius detection, dead code analysis, and hybrid search. Zero-dependency binary.

---

### 🟣 [docx-go](https://github.com/theAstiv/docx-go)
> Go library for creating, reading, and modifying `.docx` files without losing unknown content

Go · OOXML · JSON templating · Apache-2.0 · `v0.3.0`

Builds reports from scratch (images, hyperlinks, styled tables, page numbers, TOC) or fills Word templates from JSON with `{{#each}}` / `{{#if}}` blocks. Every generated document passes the OOXML schema validator and opens cleanly in Word, LibreOffice and Google Docs, with no "Repaired document" prompt.

### 🟢 DPDPA tooling
> Free compliance checks for India's Digital Personal Data Protection Act

- **[DPDPA Website Check](https://statechecksecurity.com/scan)**: scans a site's public pages for DPDP Act gaps (notices, consent, trackers) and writes a plain-language report.
- **[DPDP Gap Identifier](https://statechecksecurity.com/dpdpa/gap-identifier)**: a guided self-assessment that maps your answers to specific obligations under the Act and Rules.
